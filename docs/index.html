The measurement

Every uncaptured ray in Schwarzschild has a turning point at r_t ≥ 1.5 r_s, where f = 1/3. So the blueshift is capped at √3, and with σ ~ E^α the cross-section ratio is capped at 3^(α/2) — exactly. Saturation flattens α at high energy, so the ceiling falls with energy. That derivative is the signature: a PDF refit shifts the normalisation, it does not produce the tilt.

How to run it

The transport code needs only g++ and the STL. The dipole code has its own build; the two are coupled by file — a cross-section table with declared conventions — and never by link. Full instructions in the command reference above.
