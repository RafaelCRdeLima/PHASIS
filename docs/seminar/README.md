# PHASIS seminar

A self-contained web presentation of PHASIS: colour-dipole neutrino cross
sections from 10³ to 10¹⁴ GeV, and their transport along null geodesics in
Schwarzschild. Prepared for the DUNE collaboration meeting at Unicamp, 2026.

Same deck engine as the HADROS3 seminar — one HTML file, no build step, no
network at runtime.

## Present locally

Open `index.html` directly, or serve the directory:

```bash
python3 -m http.server 8000 --directory docs
```

then open `http://127.0.0.1:8000/seminar/`.

Controls: arrow keys or Space to navigate, `F` for fullscreen, `O` for the
overview, `N` for speaker notes, `?` for help. Every slide carries a speaker
note.

To export a PDF, print from the browser in landscape — each slide is one
16:9 page. The two dashboards print as they stand at the moment of printing.

## The two dashboards

Both are live and use no network.

- **Slide 09 — σ(E).** The real production tables, subsampled to 56 points per
  series and embedded in the file. Hover the plot: the readout gives σ_CC,
  σ_NC/σ_CC, α_eff and the ceiling 3^(α/2) at that energy. Sweeping left to
  right shows α flattening and the ceiling following it down, which is the
  whole measurement in one gesture.

- **Slide 15 — the geodesic.** The exact Schwarzschild photon orbit,
  `d²u/dφ² = −u + (3/2) r_s u²`, integrated with RK4 in the browser at each
  slider move. The readouts (turning point, blueshift, deflection) are computed,
  not tabulated. Push the slider to the left edge and the blueshift approaches
  √3 — the only place the ceiling is attained.
